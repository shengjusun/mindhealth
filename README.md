# HarmonyOS NEXT 心理健康辅导系统

## 一、项目简介

HarmonyOS NEXT 心理健康辅导系统是一个面向个人情绪记录、心理测评与状态展示的前后端分离项目。  
项目目标不是完成简单页面展示，而是围绕“登录注册 → 个人资料 → 情绪日记 → 心理测评 → 记录统计 → 首页状态展示 → AI陪伴聊天”构建完整业务闭环，并作为可演示、可写简历、可用于面试讲解的作品进行打磨。

本项目重点体现以下能力：

- HarmonyOS NEXT 应用开发能力
- ArkTS/ETS 页面开发与组件封装能力
- Java 后端基础与 Spring Boot 项目开发能力
- JWT 登录鉴权与本地登录态管理能力
- MySQL 数据落地与业务接口联调能力
- 前后端分离项目中的真实问题定位与排查能力

---

## 二、项目背景

随着学习、生活与就业压力增加，情绪记录与心理状态自我管理的需求越来越明显。  
相比单纯的信息展示类应用，本项目希望围绕“用户心理状态记录与反馈”做出一个更完整的产品雏形，使用户能够完成以下操作：

- 登录系统并管理个人信息
- 记录日常情绪日记
- 完成心理测评并保存结果
- 在个人中心和首页查看自己的状态摘要与统计信息
- 使用 AI 聊天页面进行基础陪伴式交互

因此，本项目并非简单的静态页面堆砌，而是一个包含真实用户数据、登录鉴权、业务入库、结果展示与页面联动的应用项目。

## 八、登录鉴权流程

本项目采用 JWT 作为登录鉴权方案，整体流程如下：

1. 用户在登录页输入账号与密码
2. 前端调用登录接口
3. 后端校验用户信息与密码
4. 校验成功后生成 JWT token
5. 前端通过 `AppAuthService` 保存 token 与用户信息
6. 后续接口请求统一由 `ApiService` 附带 `Authorization` 请求头
7. 后端通过 Spring Security + JWT 过滤器完成请求鉴权
8. 用户退出登录时清空 token 与本地缓存

该方案的优点在于：

- 适合前后端分离项目
- 便于移动端管理登录态
- 可减少服务端 session 依赖
- 更适合接口统一鉴权

## 九、项目亮点

### 1. 前后端完整联调
本项目不是静态页面展示，而是完成了从页面、接口到数据库的完整打通。

### 2. JWT 登录鉴权闭环
实现了从登录、token 获取、token 持久化、本地恢复到受保护接口访问的完整链路。

### 3. 测评结果入库与展示
用户完成测评后，结果会写入数据库，并在“我的记录”“我的页统计”“首页状态展示”中复用。

### 4. 资料编辑与头像回显链路
项目实现了用户资料编辑、头像上传、头像路径更新、本地缓存同步与页面回显。

### 5. 真实工程问题排查经验
在开发过程中，项目真实遇到并处理过如下问题：

- 前后端返回结构不一致
- 页面将 ApiResponse 当作裸数组解析
- JWT 鉴权链 anonymous / 403 问题
- 首页版本冲突导致功能丢失
- 头像回显、缓存与页面刷新问题
- 页面首帧渲染与异步返回造成的闪动问题

这些问题使项目更接近真实工程实践，而不只是页面拼接。
